# Steam fresh economic intake v2 — official API migration

2026-11-23 KST. Historical legacy intake stopped before retaining any data; two legacy probes returned HTTP 302 to the store homepage. Official documentation now deprecates `/appreviews` and identifies the unauthenticated replacement `GET https://api.steampowered.com/IUserReviewsService/GetAppReviews/v1/` with `input_json`. A user-run anonymous one-review HTTP probe returned 200 application/json. Source: https://partner.steamgames.com/doc/webapi/IUserReviewsService?l=english. No evidence of a successful full corpus collection yet.

Keep original frozen app IDs, date window, first-page cap, source scope, exclusion rules and five-per-arm target. New API's date-range filters enforce the same UTC window server-side. No publisher key or login; one request per app and no retries or redirects. New separate run ID, no legacy fallback. Accept HTTP 200 and structured review array (without legacy `success` property), normalize numeric IDs, discard hardware, playtime, and profile data at transport boundary; retain author ID only ephemerally for the cap. Purchase/free/refunded flags are contextual platform observations, not proof of payment for a proposed business solution. New output is confined to local-only research custody. No historical source eligibility or prior authorization change.
