# 크몽 정기 실적 보고서 상품 등록안

상태: 등록 전 초안. 기존 엑셀 정리·검수 상품과 별도 판매. 고객 주문·리뷰·결제 실적을 주장하지 않는다.

## 상품명

엑셀 CSV 주간 월간 실적 보고서 제작 및 데이터 검수

## 판매 조건

STANDARD 39,000원 / 작업 기간 2일 / 수정 1회. 동일한 열 구조의 CSV 또는 단일 시트 XLSX 최대 3개, 전체 1,000행·15열, 각 2MB 이하. 주간 또는 월간 중 한 종류, 식별 키·날짜·분류·수량 필드 각 1개, 같은 단위의 비음수 정수 수량. 구매 전 샘플 및 범위 협의 필수. 자동 갱신 프로그램이나 맞춤 대시보드 개발을 포함하지 않는 보고서 1회 제작 서비스.

## 상세 설명 (붙여넣기)

매주 또는 매월 여러 엑셀 파일을 모아 실적을 집계하고 계신가요?

동일한 형식의 엑셀·CSV 자료를 취합하고, 중복·누락·불일치 등을 확인한 뒤 주간 또는 월간 실적 보고서를 엑셀로 정리해 드립니다. 원본을 수정하지 않고, 확인이 필요한 항목은 집계에서 제외하고 별도로 표시합니다.

**이런 분께 추천합니다**

- 시설 점검, 작업량, 제작 건수 등 반복적인 수량 실적을 집계하는 분
- 여러 파일의 동일한 자료를 취합하며 중복 확인이 필요한 분
- 보고서 수치가 어떤 원본 행에서 나왔는지 확인하고 싶은 분

**제공 결과물**

- 기간별 총수량과 분류별 실적, 반영 행 수
- 데이터 검수 요약 및 정리 결과
- 완전 중복 목록과 확인 필요 목록
- 원본 파일·행 위치 기록

**작업 범위**

- 같은 열 구조의 XLSX 또는 CSV 최대 3개, 전체 1,000행·15열, 각 2MB 이하
- 주간(월요일 시작) 또는 월간 보고서 1종
- 날짜는 YYYY-MM-DD 텍스트, 수량은 0 이상의 정수, 분류 항목 1개
- 최초 합의 범위 내 수정 1회

**진행 과정**

1. 크몽 메시지로 개인정보와 기밀정보를 제거한 10~20행 샘플과 원하는 결과를 보내주세요.
2. 파일 구조, 집계 주기, 식별 키, 분류 기준을 확인하고 가능 범위를 안내합니다.
3. 결제 후 자료를 정리하고 검수합니다.
4. 주간 또는 월간 실적 XLSX와 확인 필요 내역을 전달합니다.

**주의 사항**

보고서는 전달받은 자료 기준의 결과물입니다. 신규 파일을 추가하면 자동 갱신되는 프로그램은 포함하지 않습니다. 서로 다른 수량 단위는 합쳐 계산하지 않으며, 중복 키에 다른 값이 있거나 필요한 정보가 잘못되어 있으면 확인 목록으로 분리합니다. 수식·매크로·병합 셀·여러 시트·서식 보존·PDF 변환·세무 및 금융 판단·민감정보 처리는 기본 범위에 포함하지 않습니다. 가상 포트폴리오는 실제 고객 주문 사례가 아닙니다.

## 의뢰인 준비사항

비식별 샘플 10~20행, 전체 파일 수·행 수·열 수, 식별자·날짜·분류·수량 열의 이름, 주간/월간 여부, 원하는 결과 예시. 민감하거나 기밀인 자료는 제거 후 제공.

## FAQ

**매월 자동으로 보고서가 생성되나요?** 이번 상품은 1회 보고서 제작이며 반복 주문은 동일한 구조의 새 파일로 다시 처리합니다. 예약 실행·자동 갱신·설치 제공은 제외합니다.

**오류가 있으면 어떻게 하나요?** 동일 식별자의 상충 데이터와 잘못된 필수 값을 임의로 수정하지 않고 확인 필요 목록에 남기며 해당 행은 집계하지 않습니다.

**기존 엑셀 정리 상품과 뭐가 다른가요?** 정리 상품은 원본 데이터 취합과 검수 중심, 보고서 상품은 그 결과로 기간별·분류별 실적까지 계산한 XLSX를 제공합니다.

## 포트폴리오 문구

가상 시설 점검 기록 2개 파일을 이용한 월간 실적 보고서 예시입니다. 정상 반영 6행, 완전 중복 1행, 확인 필요 6행으로 구분하고 9월 14건, 10월 17건을 집계했습니다. 실제 고객 주문이 아닌 기능 설명용 샘플입니다.

## 내부 원가 가정 및 판매 판단

이전 49,000원 시험가에서 39,000원으로 조정. 29,000원 기본 정리 상품과 10,000원 차이를 두며, 39,000원은 기본 범위에 한정한다. 가정 수수료 20%, 시간가치 25,000원/h, 기타 1,000원: 30분 작업 시 17,700원, 45분 시 11,450원, 60분 시 5,200원 공헌이익. 실제 수수료·재작업·세금은 별도로 기록. 최초 주문은 예상 총 45분 이하, 범위 초과 주문은 무리하게 수락하지 않는다. 기존 상품 가격 변경이나 신규 상품 공개 등록은 사용자의 별도 실행에 따른다. 실제 결제 1건 이상 및 두 독립 고객 수락, 작업시간·검수·공헌이익 게이트 확인 전 판매 검증 완료로 보지 않는다.
