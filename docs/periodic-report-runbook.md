# 정기 실적 보고서 파일럿 운영

## 주문 전 확인

최대 3개 파일, 전체 1,000행/15열, 파일당 2MB 이하. 동일한 열 이름·순서의 CSV 또는 값 중심 단일 시트 XLSX만 접수한다. 고객과 고유 키, 날짜, 분류, 수량 열을 합의하고 비민감 샘플로 검증한다. 날짜는 `YYYY-MM-DD` 텍스트, 수량은 0 이상 정수, 분류는 공백이 아닌 텍스트. 수식·매크로·병합 셀·복잡한 서식·민감자료는 제외. 다른 단위의 수량은 혼합 집계하지 않는다. 실제 납품 전 원본과 보류 항목을 고객과 대조한다.

## 실행

Python 환경에 openpyxl이 필요하다. 저장소 루트에서 다음과 같이 실행한다. 출력 경로는 존재하지 않는 새 디렉터리여야 한다.

```bash
python3 -m src.periodic_report --key id --date-field day --category-field group --quantity-field qty --frequency monthly --output /tmp/report-order-001 /tmp/a.csv /tmp/b.csv
```

`weekly`는 월요일 시작, `monthly`는 달력 월 기준. 지정 필드가 실제 헤더와 일치해야 한다. 기존 엑셀 정리 CLI의 동작은 변경하지 않는다.

## 출력과 확인

- `delivery-draft.xlsx`: 기간별 실적(합계와 분류별 수량), 검수 요약, 정리 결과, 중복 기록, 확인 필요, 원본 행 기록, 원본 파일의 해시.
- `clean-draft.csv`, `duplicates.csv`, `unresolved.csv`, `review.json`: 같은 최종 분류와 원본 좌표를 유지하는 내부 검수 기록.
- 집계에는 최종 반영 행만 포함한다. 정확한 중복은 1회만 집계하고 충돌 키 전부, 키/날짜/분류/수량 오류는 보류한다. 전부 보류라면 실적 시트에 반영 가능한 데이터 없음을 표시한다.
- XLSX는 고정 스냅샷이다. 원본 수정/추가 시 새 출력으로 재실행하고 사람이 검수한다. 기존 출력 디렉터리를 재사용하거나 실패한 출력물을 납품하지 않는다. 파일명과 시트명은 일반 문자를 사용한다.
- 수량/기간 합계 15자리 초과, 구조 오류, 지원하지 않는 파일은 자동 처리하지 않는다.

## 판매 검증

기술 검증은 합성 자료 기준이다. 실제 주문은 비민감 샘플 확인→범위·검수 기준 합의→처리→보류 항목 검토→납품 순서로 진행한다. 상담·수정 포함 총 소요시간 60분 이내와 공헌이익 기준을 별도 측정하기 전 상업적 검증 완료로 판단하지 않는다. 기존 크몽 등록 가격·범위는 자동 변경하지 않는다.
