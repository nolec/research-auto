# 소형 CSV 대조 유료 검증 — 등록 전

2026-11-23 KST. 기존 크몽 엑셀 상품과 중복 등록하지 않는다. 별도 가상 CSV 테스트에서 키 기반 금액 대조가 필요한 점을 확인하기 위한 확장 실험만 준비. 실제 금융/개인정보, 은행 내역, 회계 시스템 계정, API 키를 받지 않는다. 기존 상품의 금융자료 제외 정책도 변경하지 않는다. 익명화된 비민감 예시만 검토하고 고객이 직접 익명화한 결과의 적합성은 사전 합의한다. 실제 고객 주문은 아직 0건.

## 제공할 수 있는 검증 결과

- CSV 2개: 청구서 `invoice_id,amount,currency`, 입금 `payment_id,invoice_id,amount,currency`. 고객이 이미 부여한 정확한 참조 ID, 통화 1개 기준으로 접수. 각 1,000행 이내. 금액 양수, 지원 통화 USD/GBP/CAD/EUR/KRW. 실제 계좌·이름·연락처는 제외.
- 청구서 단위 일치, 부분 입금, 미입금, 초과 입금, 중복 ID 또는 통화 충돌 검토 목록; 대응되지 않은 입금 행 번호; 원본 행 수 대조. 동일 ID의 복수 입금은 유일한 payment ID만 합산. 출처 행 번호 보존. 거래 확정, 회계 장부 수정, 독촉 메시지 발송, 회계·세무 자문, 날짜 기반 연체 판단, 환불·환전·수수료 추정 제외.
- 최소 샘플로 기준 검증, 상담부터 납품까지 30분 목표. 사전에 초과하면 거절 혹은 범위 재합의. 29,000원 가설, 기존 엑셀 서비스와 같은 실험 가격. 수수료 20%, 기타 비용 1,000원, 시간 가치 25,000원/h 가정 시 30분 기준 9,700원 공헌이익; 실제 수수료·작업시간·수정 비용으로 재검증.

## 가상 예시 (USD, 고객 데이터 아님)

| 청구서 | 청구액 | 일치 입금 | 차액 | 판정 |
| --- | ---: | ---: | ---: | --- |
| 0001 | 10.00 | 10.00 | 0.00 | 일치 |
| 0002 | 20.00 | 8.00 | 12.00 | 부분 입금 |
| 0003 | 30.00 | 0.00 | 30.00 | 미입금 |
| 0004 | 40.00 | 45.00 | -5.00 | 초과 입금 |

입금 5행 중 4행 일치 배분, 1행 연결 대상 없음. 중복 ID 및 통화 불일치 시 관련 전체 행은 검토로 분리하고 잔액을 확정하지 않는다. 실제 데이터 누락 또는 잘못된 참조 ID는 판별할 수 없으므로 결과를 회계상 확정 사실이라고 하지 않는다.

기존 7일 유료 검증 정책과 같은 기준: 적격 문의 10건, 서로 다른 고객 2명 이상 유료 수락, 완료 결제 1건 이상, 완료 주문 공헌이익 5,000원 이상. 그 전에는 별도 회계 SaaS 개발/광고비/유료 계정/자동 영업 금지. 플랫폼 등록 전 사용자 승인 필요. 실제 유료 매출과 전체 작업시간 미측정. 기존 자동화 서비스를 유지하며, 이 후보도 다른 분야와 같은 탐색 게이트로 평가한다. 이 실험은 엔진 V7 정확도나 공식 사업 기회 승격이 아님.
